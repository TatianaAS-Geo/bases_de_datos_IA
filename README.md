# Bases de Datos para la Inteligencia Artificial - FIUBA

Tatiana Arenas Suárez

Este repositorio contiene los trabajos prácticos y materiales desarrollados en el marco de la materia **Bases de Datos para la Inteligencia Artificial** de CEIA (FIUBA).

## Estructura del repositorio

- `TP_1/`: Introducción a bases de datos relacionales y consultas SQL.
- `TP_2/`: Bases de datos no relacionales: introducción a MongoDB.
- `TP_3/`: Bases de datos grafos, neo4j.
- `TP4/`: Vector databases y almacenamiento semántico de datos.
- `TP_final/`: Trabajo integrador final aplicando a MongoDB.
